# Board samples

Example shapes for a product delivery board. After `bash setup.sh /path/to/product`, live files live under the product’s `.agents/delivery/`.

| File | Purpose |
| --- | --- |
| `STATUS.md` | Live / blocked / merged snapshot |
| `ACTIONS.json` | Orchestrate tick (merged / needs_review / blocked) |
| `TICKET-BOARD.md` | NOW / NEXT / PARK |
| `TICKET-TEMPLATE.md` | Done-when + In/Out/Forbidden |
| `PLAYBOOK.md` | Quality bar excerpt (max 1–2 jobs, evidence) |
