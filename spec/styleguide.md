# Styleguide (sample craft rules)

Agents implementing UI tickets must follow these rules. Taste fails if violated.

## Density & hierarchy
- Prefer scannable hierarchy over decorative chrome.
- One primary CTA per view; secondary actions quieter.

## Motion
- Subtle, purposeful; no looping distraction.
- Respect `prefers-reduced-motion`.

## States
- Empty / loading / error / success must all be intentional (no blank crash).
- Errors are recoverable with a next step.

## Taste fails if
- Flat wash / generic AI slop layout
- Broken Preview happy-path
- Copy that lies about what the product does
