# Bot roles (one-liners)

| Bot | Does | Does not |
| --- | --- | --- |
| **Delivery** | Spawns/continues limen, opens draft PRs, owns STATUS.md, keeps 1–2 jobs moving | Merge; owner product taste |
| **Reviewer** | PASS / HOLD / FAIL + act-ons from evidence + Done-when | Merge; expand scope |
| **Taste** | UI craft HOLD/PASS on Preview | Merge; rewrite backend |
| **SDLC** | Playbook / process / harness docs | Product feature scope |
| **Architect** | Design choice when it matters; keep diffs small | Implement the whole epic alone |
| **Coordinator (thin)** | Merge after PASS; queue order; taste URLs | Coding implementation; FYI spam |
